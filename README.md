# Meal Week — offline meal-plan app

A single self-contained web app for one week of meals: shopping list (by aisle),
a weekend batch-cook guide, and the 7-day plan — all tap-to-tick, remembered on
your device, and fully **offline** once loaded.

- **Open it:** see the live link in this repo's GitHub Pages (Settings → Pages).
- **Install to your phone:** open the link in Chrome → menu ⋮ → *Add to Home screen*.
  It then runs like an app, no internet needed.

Generated by a personal, file-based meal-planning engine. This repo contains
**only the published app** — no profile, health, or personal data.
